# CutMind

Prompt-driven, multi-agent AI video editor — 100% local, free and open source.

Import raw clips, type *"make a 30 sec travel reel, fast cuts, warm color, add captions, remove
silence"*, and a team of agents plans the edit as an **Edit Plan JSON**; a deterministic FFmpeg
renderer executes it; a **Reviewer** checks the real output file against the prompt, scores every
agent, retries the weak ones and turns mistakes into **lessons** that are injected into their
prompts next time.

```
you (Hinglish / voice) ─► Prompt coach ("Samajh gaya 👌", clean English prompt)
   ─► LangGraph: understand ─► analyze ─┬─► audio ─► cutter ─┬─► effects ─► render ─► review ─► finalize
                                       └─► color ───────────┘                  ▲          │
                                                                               └── fix ◄──┘
      AgentRouter picks ~20 of 195 specialists · checkpoints · live events (SSE) · lessons · memory
```

Runs on a CPU-only laptop (no GPU, no paid API). Docs: LOCAL_SETUP · CPU_MODE · AGENTS · LANGGRAPH · MCP ·
MEMORY · MODEL_SETUP · TESTING · TROUBLESHOOTING · PROJECT_AUDIT · TEST_REPORT.

## Quick start (3 commands)

```bat
setup.bat
run-all.bat
start http://localhost:8081
```
(macOS/Linux: `./setup.sh`, `./run-all.sh`, open http://localhost:8081.) API docs: http://localhost:8000/docs.

### Deploy to a server (Docker)

```bash
cp .env.example .env        # set CUTMIND_API_KEY
docker compose up -d --build
```
The image contains FFmpeg, the AI model and whisper — no external AI service, no API bills. In the app's
Settings, enter the server URL and the same API key.

## Repository layout

| Path | What |
|---|---|
| `backend/cutmind/` | FastAPI app (`api.py`), jobs, SQLite (`db.py`), Edit Plan (`plan.py`), renderer, LLM client, prompt parser |
| `backend/cutmind/agents/` | `director`, `analyzer`, `audio`, `cutter`, `color`, `effects`, `reviewer` — one job each |
| `backend/assets/music/` | royalty-free music beds (generated by FFmpeg) |
| `backend/cutmind/tools/` | Tier 1 tool engine: 105 skills as calls (`engine.run`), the prompt matcher (`parse.py`), time modes, plan invariants |
| `skills/tier1/` | one YAML spec per Tier 1 skill (params, time modes, synonyms, examples, test) — status in `docs/TIER1_STATUS.md` |
| `catalog/` | skill catalog built from what passed the variant difference test (`build_catalog.py`) — `docs/SKILL_CATALOG.md` |
| `mobile/` | Expo + TypeScript app (UI only): Projects, Import, Editor (Skia timeline), Agent Activity, Scoreboard, Export, Settings |
| `tests/` | pytest unit + integration (real FFmpeg) + failure tests; generated media; JSON results |
| `docs/` | test frame contact sheets, extra notes |
| `ARCHITECTURE.md` · `SETUP.md` · `TEST_REPORT.md` · `CHANGELOG.md` · `SAMPLE_PROMPTS.md` | docs |

## Stack

FastAPI · Pydantic · SQLite · FFmpeg · faster-whisper (tiny) · PySceneDetect · librosa · OpenCV ·
in-process Hugging Face LLM (Qwen2.5-1.5B-Instruct, ONNX Runtime, CPU) · Docker · Expo / React Native · react-native-skia · Reanimated.
